# 42 cursus

My projects from [42 Abu Dhabi](https://42abudhabi.ae), collected in one place. Each folder was its own repo; history is kept via `git subtree`.

| Project | What it is |
|---|---|
| [libft](libft) | My own C standard library, reused by most later projects |
| [get_next_line](get_next_line) | Read a file one line at a time from any file descriptor |
| [ft_printf](ft_printf) · [bonus](ft_printf_bonus) | `printf` rebuilt from scratch with variadic arguments |
| [born2beroot](born2beroot) | Hardened Debian server setup and a monitoring script |
| [push_swap](push_swap) | Sort a stack with a limited instruction set in as few moves as possible |
| [so_long](so_long) | Small 2D game on the MiniLibX graphics library |
| [Dining-philosophers](Dining-philosophers) | The classic concurrency problem with threads and mutexes |
| [Hashtable](Hashtable) | A hash table in C |
| [Cpp-practice](Cpp-practice) | C++ modules: OOP, templates, the STL |
| [ft_containers](ft_containers) | STL containers (vector, map, stack) reimplemented in C++98 |
| [inception](inception) | A small multi-service stack with Docker Compose, each service built from its own image |
| [computer_graphics_project](computer_graphics_project) | A Python graphics scene built from shapes |
| [python-42](python-42) | Python piscine exercises |
| [reset-42-docker](reset-42-docker) | Script to reset Docker data on the 42 lab machines |
